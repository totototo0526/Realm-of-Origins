# フェーズ4 検証結果と解説（Walkthrough）

## 1. 概要と目的
フェーズ3では、自ら育てて放出した第1世代の古参コンビ（重騎士バルガス＆瞬影のクロード）が率いるライバルギルド『黒曜の旅団』に、第5世代の現主力部隊が模擬GvGで惨敗（0勝1敗）するドラマが確認されました。

フェーズ4ではヘッドレスエンジンの最終仕上げとして、以下のシステムを実装・連動させました：
1. **BOM（部品表）連動型・動的市場 (`src/market.rs`)**:
   - 在庫の偏りによって価格が上下するダイナミックプライシング（0.3倍〜3.0倍キャップ）。
   - 完成品（白ポーション・ダマスカス短剣）が市場から買い占められると、街の工房が補充のために原材料（白ハーブ・鋼鉄・鉄鉱石・石炭）を連鎖的に消費する「プル型需要連鎖」。
2. **控え部隊の裏・自動派遣（オートチェス型ファーミング） (`src/dispatch.rs`)**:
   - 一軍（メイン）から溢れた2軍控えメンバーを、白ポーション等の消耗品をコストとして開拓済み狩場へ遠征派遣。
   - 商人（運搬・獲得量UP）＋支援（セルフヒール・消耗品削減）＋前衛（危険排除・レア率UP）による「完全自給自足トリオ・シナジー」を形成。
3. **対ライバル用メタ戦術とビルド拡張 (`src/engine.rs`, `src/models.rs`, `mods/core/skills.ron`)**:
   - 宿敵・バルガスの鉄壁装甲（VIT 80 / 高DEF）を逆手に取って大ダメージを与える**錐効果スキル【ヴァイタルストライク】**（`is_piercing_def`）。
   - クロードの必中バッシュ猛攻を耐え抜くための緊急全体回復スキル【サンクチュアリ】（`sanctuary_heal`）。
   - 街のNPC化した初代鍛冶屋ボブの永続バフ（全味方武器ATK +3%）をGvG戦闘オーラへ合算。
   - 相手のVITをトリガーとするガンビット条件 `Condition::TargetVitAbove(threshold)`。

これらを駆使し、**「自作自演の相場操作（市場ハック）による資金調達 → クホホ工場での神話過剰精錬 → 第6世代新エースの育成 → 宿敵『黒曜の旅団』へのGvGリベンジ（雪辱）」**という完全自律型ゲームループを実証しました。

## 2. 4ステップ検証シナリオの実行詳細

### 【Step 1: BOM連動市場のダイナミックプライシング検証】
- 遠征と精錬の準備として、市場から「白ポーション120個」と「ダマスカス短剣12本」を一斉購入（投資総額: 434,400 Zeny）。
- これにより、街の工房が自動で補充生産を開始：
  - 白ポーション補充のため、白ハーブ 240個・空瓶 120個を消費。
  - ダマスカス短剣補充のため、鋼鉄 36個・オリデオコン 12個を消費。
  - 鋼鉄補充のため、鉄鉱石 72個・石炭 36個を再帰的に消費。
- **結果**:
  - 市場の「白ハーブ」「石炭」「鉄鉱石」の在庫が激減し、プレイヤーからの買取価格が急騰しました。

### 【Step 2: 自動派遣部隊による高騰素材のピンポイント採掘（市場ハック金策）】
- 控え部隊（商人トミー、支援エレン、護衛レオン）を「廃坑深層」へ35サイクル、「妖精の薬草園」へ25サイクル派遣。
- 黄金トリオシナジー（素材獲得+50%、消耗品消費-50%）により、白ポーションの消費を抑えつつ大量の石炭、鉄鉱石、オリデオコン、白ハーブを採掘。
- 掘り出した素材を高騰した市場へ商人のOvercharge (+24%) 込みで全売却。
- **結果**:
  - 初期投資額 434,400 Zeny に対し、売却総額 **734,765 Zeny** を獲得。
  - **差引純利益 +300,365 Zeny の大黒字**を達成し、手元には無償でダマスカス短剣と予備ポーションが残りました。

### 【Step 3: 対『黒曜の旅団』決戦用ビルドの育成とクホホ工場】
- 獲得した莫大な利益とベース武器を使い、名匠ハンスがワークオーダーでダマスカス短剣の一斉過剰精錬を実行。
- 完成した『+10 致命のダマスカス[4]』（限界突破ボーナス: 防御無視ダメージ+15）に、ソルジャースケルトンカード（クリティカル率UP）を4枚装着。
- 先輩コンビ（ハンス＆ルカ）の引率によるセルフ養殖（オーク連戦）で、第6世代エリートシーフ『アリア』をLv.99まで高速育成。
- アリアに対ライバル特化ガンビットを設定：
  - `Condition::TargetVitAbove(50)` ➔ `Action::UseActiveSkill("vital_strike")`
  （敵のVITが50以上なら、錐効果で敵のDEF/VITを逆手に取り貫通ダメージを撃ち込む）

### 【Step 4: 運命の再戦！ 模擬GvG リベンジマッチ】
- **開戦**:
  - 我らが『新生オリジンギルド』は、鍛冶屋ハンスの武器研究オーラと街NPCボブの永続バフが重畳（武器ATK +11%）。
- **戦闘の推移**:
  - Tick 0〜24: アリアの【ヴァイタルストライク】が、宿敵の要塞前衛・重騎士バルガス（VIT 80）に対して一撃 **3,100〜3,300超** の致命的貫通ダメージを連続で叩き込み、わずか24 Tickでバルガスを撃沈粉砕！
  - クロードの必中バッシュによってルカが落とされるも、高精錬防具を纏ったハンスとアリアが戦線を維持。
  - Tick 36: アリアのクリティカル防御無視攻撃が鉄腕エリックを一撃（1,541ダメージ）で粉砕。
  - Tick 44: アリアのクリティカル連打が瞬影のクロードを撃破（1,569ダメージ）。
- **決着 (Tick 45)**:
  - **『新生オリジンギルド』が2名生存で完全勝利！** 前回の敗北から見事なリベンジを果たしました。

## 4. 結論
フェーズ4の実装により、以下の自律的ゲームループが完全に成立しました：
1. **マクロ経済（市場）と生産（BOM）の連鎖**: 完成品の大量消費が一次素材の相場を動かす。
2. **バックグラウンド自動化（控え部隊派遣）**: 放置時間・裏作業で相場急騰素材をピンポイント採掘し、富を蓄積。
3. **メタゲーム攻略（ガンビット＆装備）**: 過去に自ギルドを離脱した強敵のビルド特性（VITタンク）に対し、相場ハックで得た資金と特効スキル（錐効果）で対抗策を構築。
4. **ドラマの完結（GvG雪辱）**: 敗北の屈辱を経済と戦術の力で乗り越え、宿敵を打ち破るカタルシス。
