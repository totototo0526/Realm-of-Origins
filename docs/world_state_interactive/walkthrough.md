# フェーズ5 成果報告書：完全データ駆動化・統合ワールドステート・セーブ/ロード・インタラクティブゲームループ

## 1. 概要
フェーズ1〜4で実証された戦闘・ガンビット・クホホ精錬・世代交代・FA移籍・BOM連動市場・自動派遣の全コアロジックを統合し、プレイヤーが実際に意思決定を行いながら何世代もギルドを運営・冒険できるステートフルなゲームエンジン（`WorldState`）へと昇華させました。

さらに、外部ファイル（RON）による完全データ駆動化、ファイル永続化（セーブ＆ロード）、および「自動検証モード（`--headless-demo`）」と「対話型ギルド運営モード（通常起動）」の両立を実現しました。

## 2. 設計判断（ADR）とモジュール構成の変更点

### ADR-001: アイテム・レシピ・エリア定義の完全外部化
- **背景**: 以前はダマスカスやポーションのBOMレシピ、および派遣先が一部コード内にハードコードされていました。
- **決定**:
  - `mods/core/items_recipes.ron`: 市場アイテム・ベース装備・BOMレシピツリーを統一形式で定義。
  - `mods/core/areas.ron`: 狩場定義（出現モンスター、推奨Lv、派遣ドロップテーブル、消費スタミナアイテム）を定義。
  - `ItemDef` に `is_equipment`, `base_atk`, `base_def`, `slots` を持たせることで、一般消費財・素材・装備品を統一してRON定義可能にしました。

### ADR-002: 単一統合ステート `WorldState` とワールドTick同期進行
- **背景**: ゲームの全状態（世代、資産、倉庫、現役キャラ、同行PT、ギルド名簿、市場、派遣、ライバルギルド）を一つのデータ構造に集約し、RONで一括保存・復元可能にする必要がありました。
- **決定**:
  - `src/world.rs` に `WorldState` 構造体を新設。
  - プレイヤーが冒険や活動を1回行うごとに `world.advance_turn(elapsed_ticks, &db)` が呼ばれ、裏で以下の3要素が同期して進行します：
    1. **自動派遣部隊の消化と回収**: 派遣所要Tickに達した時点で自動帰還し、倉庫へ物資格納＆経験値獲得。
    2. **動的市場の自然回復とBOM補充**: 商人ギルドの流通により在庫が8%回復し、高騰相場が緩やかに落ち着く。
    3. **ライバルギルド群の裏リーグ戦**: 3大ライバルギルド同士が模擬対抗戦を行い、勝敗ログと戦力微増（MVPのLv/ステータス上昇）が発生。

### ADR-003: 3大ライバルギルドリーグの常設
- **背景**: 自ギルドのライバルとして、特性の異なる複数の勢力が切磋琢磨するリーグ構造が必要でした。
- **決定**:
  1. **『黒曜の旅団』**: 物理速攻＆重装甲（ダミアン、ゴルドー、レオン）
  2. **『鉄棺騎士団』**: 防御・反射特化（聖騎士アイゼン、重歩兵ジーク、修道女ヒルダ）
  3. **『灰燼の学派』**: 魔法・支援特化（大魔導アルス、付術師セレーナ、詠唱士カレン）
  自ギルドからFA移籍したメンバーは、シナジー引力（相性スコア）によって最も相性の良いギルドへ自動入団します。

### ADR-004: ヘッドレス自動検証とインタラクティブCUIの両立
- **背景**: 回帰テスト用の自動シナリオ実行と、人間が遊べるCUIループを両立させる必要がありました。
- **決定**:
  - `cargo run -- --headless-demo`: 全システム（初期化〜冒険〜派遣〜市場〜精錬〜転生〜GvG〜セーブ/ロード完全一致アサーション）を自動実行する回帰テスト。
  - `cargo run`: プレイヤーが標準入力（番号選択）で遊べるステートフルなCUIゲームループ。

## 5. インタラクティブモード操作ガイド

通常起動 `cargo run` でCUI司令部が立ち上がります。

```bash
cargo run
```

### コマンド一覧
1. **[1] ⚔️ 【冒険・養殖へ出る】**
   - 挑戦するエリアを選択（例: `1` 廃坑深層、`2` 妖精の薬草園、`3` オーク集落の地下洞窟）。
   - 現役主人公と同行パーティーがモンスターと3連戦を実施。
   - 経験値配分・レベルアップ、ドロップ換金Zenyを獲得。
   - エリアに応じたTick数が経過し、裏で派遣部隊の採掘や市場の自然回復、ライバルギルド同士の裏リーグ戦が同期進行します。
2. **[2] 🛡️ 【編成・装備・ガンビット】**
   - 現役キャラの武器装備変更、倉庫のカード装着、希少品保護ロック切替（精錬破壊防止）、および敵性格（Swift必中、Heavy強打）に応じたガンビット作戦の設定。
3. **[3] 🔨 【全自動クホホ工場】**
   - 倉庫のベース装備を選び、鍛冶屋キャラクターにワークオーダー（安全圏+4停止、目標+7/+10、予算限界突破）を発行して過剰精錬を実行。
4. **[4] 📈 【動的市場（売買＆相場確認）】**
   - BOM連動によるダイナミックプライシング相場を確認。
   - 完成品やポーションの買い占め、または倉庫の採取素材を商人Overcharge価格（+24%）で売却。
5. **[5] ⛏️ 【自動派遣（遠征指示）】**
   - ギルド名簿の控えメンバー3名を選抜し、特定エリアへ遠征指示。冒険等で時間を進めると自動帰還して鉱物やハーブを倉庫に蓄積。
6. **[6] 🔄 【レガシー転生 ＆ FA処遇決定】**
   - 十分育った現役キャラを殿堂入りさせ、第N世代の新主人公（育成方針選択）を作成（先代ボーナス付き）。
   - 出撃機会の減った古参メンバーがFA宣言した際、「引き留め / 街NPC化（永続バフ） / ライバルギルドへ移籍（移籍金獲得＆敵軍強化）」を選択。
7. **[7] 🏆 【ギルドリーグ・GvG】**
   - 3大ライバルギルド（『黒曜の旅団』『鉄棺騎士団』『灰燼の学派』）を選んで3vs3の対抗戦を実施。勝利でリーグ賞金を獲得。
8. **[8] 💾 【セーブ / ロード】**
   - `saves/save_data.ron` へ現在のワールドステートを保存、またはセーブデータから復元。
0. **[0] 🚪 【ゲーム終了】**
   - 司令部を終了します。
