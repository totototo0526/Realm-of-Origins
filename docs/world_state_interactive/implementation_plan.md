# 実装計画：フェーズ5 完全データ駆動化・統合ワールドステート・セーブ/ロード・インタラクティブゲームループ

## 1. 概要
フェーズ1〜4で開発・検証した戦闘・ガンビット・クホホ精錬・世代交代・FA移籍・BOM市場・自動派遣の各サブシステムを統合し、プレイヤーが実際に意思決定を行いながら何世代にもわたってギルド運営・冒険を楽しめるステートフルなゲームエンジン（`WorldState`）へと昇華させます。

---

## 2. アーキテクチャ設計判断（ADR: Architectural Decision Records）

### ADR-001: 完全データ駆動化（アイテム・BOMレシピ・エリアの外部RON化）
- **背景**: これまで `src/market.rs` や `src/dispatch.rs` の一部にアイテム名、BOMツリー、派遣先がハードコードされていた。
- **決定**:
  - `mods/core/items_recipes.ron` を新設し、市場アイテム・ベース装備・BOMレシピを一元管理。
  - `mods/core/areas.ron` を新設し、狩場エリア（出現モンスター、推奨Lv、派遣時の消耗品コスト、ドロップテーブル）を外部定義。
  - `ModDatabase`（`src/loader.rs`）に統合ロードさせる。
- **効果**: ゲームバランスや新アイテム・エリアの追加がコード再コンパイル不要で完全にMOD対応となる。

### ADR-002: 統合ワールドステート (`src/world.rs`) とワールドカレンダー同期
- **背景**: 固定スクリプトから、プレイヤーの選択に応じたステートフルなゲーム進行へ移行する必要がある。
- **決定**:
  - `WorldState` 構造体に「世代数」「経過ワールドTick」「ギルド資産Zeny」「共有倉庫」「現役キャラ」「同行PT」「ギルド名簿」「ライバルギルドリーグ」「市場状態」「派遣状態」を集約。
  - `serde::Serialize` / `Deserialize` を実装し、`saves/save_data.ron` への保存・復元を完全自動化。
  - メインパーティーが冒険/育成を1回実行するたびにワールドTickが進み、裏で「派遣部隊の採掘」「市場の自然回復とBOM自動補充」「ライバルギルド同士の裏リーグ対戦と戦力成長」が自動的に同期進行する。
- **効果**: 1手進めるごとに裏の世界が生き生きと動くオートチェス・ペナントレース体験が実現する。

### ADR-003: 複数ライバルギルドによる「ギルドリーグ」システム
- **背景**: これまでは『黒曜の旅団』のみだったが、多様なメタ戦術とリーグ戦の楽しさを表現したい。
- **決定**:
  - 以下の3大ライバル勢力によるリーグ制を導入：
    1. **『黒曜の旅団』**: クロード（AGI速攻）＆ バルガス（VIT要塞タンク）
    2. **『鉄棺騎士団』**: 重装甲・反射・ガードに特化したVIT/DEF鉄壁ギルド
    3. **『灰燼の学派』**: オートスペル・高火力のINT魔導・支援特化ギルド
  - プレイヤーが放出したFAキャラクターは、相性スコア（シナジー引力）が最も高いギルドへ移籍して強化される。

### ADR-004: インタラクティブCUIとヘッドレス自動検証モードの両立
- **背景**: プレイヤーが実際に遊べるCUIと、CI/回帰テストや自動検証用のデモの両方が必要。
- **決定**:
  - コマンドライン引数 `--headless-demo` を備え、スクリプト実行とCUI対話実行を綺麗に分岐する。

## 3. 実装ステップ

### Step 1: Core MODの拡充とローダー拡張
1. `mods/core/items_recipes.ron` 作成
2. `mods/core/areas.ron` 作成
3. `src/models.rs` に `ItemDef`, `RecipeDef`, `AreaDef`, `DispatchDrop` 等を追加
4. `src/loader.rs` に各定義の読み込み処理を追加
5. `src/market.rs` と `src/dispatch.rs` を `ModDatabase` 連携へリファクタリング

### Step 2: 統合ワールドステート (`src/world.rs`) の新設
1. `WorldState` 構造体および関連構造体の定義
2. セーブ (`save_to_file`) / ロード (`load_from_file`) の実装
3. ワールド進行メソッド (`advance_world_turn`) の実装（派遣、市場回復、ライバルリーグ進行）
4. ライバルギルドの複数化と裏リーグ戦ロジック

### Step 3: インタラクティブゲームループとヘッドレスデモの実装 (`src/main.rs`)
1. 引数判定（`--headless-demo` vs 通常対話CUI）
2. 対話CUIメニュー（8つのアクション）
3. ヘッドレスデモの統合実行とサマリー出力

### Step 4: テストと検証
1. `WorldState` セーブ＆ロード往復一致テスト
2. BOM市場伝播テスト
3. 複数ライバルギルド・シナジー引力テスト
4. `cargo test` & `cargo run` の検証
