# フェーズ6 ウォークスルー：ヘクス空間戦場・A*経路探索・建物フットプリント・射程と陣形タクティクス

## 1. 概要と目的
フェーズ6では、フェーズ5までに構築されたステートフルゲームエンジン（`WorldState`、セーブ/ロード、BOM市場、自動派遣、過剰精錬、世代交代、模擬GvG）を一切壊すことなく、戦闘解決層を「ヘクス（六角形）グリッド空間戦場、A*経路探索、建物フットプリント、射程（Range）、範囲攻撃（AoE）、ノックバック、陣形タクティクス」を備えた**空間タクティカルエンジン**へと拡張しました。

本実装により、従来の数値上の殴り合いから、**「建物の間の狭い通路（チョークポイント）にVIT壁ナイトを配置して敵軍をせき止め、後方から長弓や範囲魔法（ファイアーボール）で安全に敵を殲滅する」**といった本格的なタクティクスや、**「Lv1の養殖キャラクターを最奥に配置して安全にパワーレベリングを行う」**空間シナジーが実現しました。また、すべてのヘクス座標はクォータービュー（アイソメトリック）2D画面のピクセル座標と相互変換可能であり、将来的なGUI描画の強固な基盤となっています。

## 2. アーキテクチャと設計判断（ADR要約）

### [ADR-005] Pointy-topped Axial座標系と2.5Dアイソメトリック比率
- **決定**: ヘクス座標系として、計算コストが低く6方向移動や距離計算が容易な **Axial座標系 (`HexCoord { q: i32, r: i32 }`)** を採用。
- **画面変換**: 将来のクォータービュー描画を見据え、横幅を基準として縦（Y軸）を **0.58倍に圧縮する2.5Dアイソメトリック比率** を適用。
  - $x = \text{size} \times \sqrt{3} \times (q + r / 2)$
  - $y = \text{size} \times \frac{3}{2} \times r \times 0.58$
  - `hex_to_pixel` およびその逆変換 `pixel_to_hex` を完全実装し、単体テストで往復精度を保証。

### [ADR-006] 矩形建物フットプリント（BuildingFootprint）とチョークポイント形成
- **決定**: クォータービュー上で正方形・長方形として描画される建築物や城壁、岩柱を、原点ヘクスとグリッドサイズ（`width x height`）で定義。
- **機能**: 矩形領域内の全ヘクスを自動的に通行不可（Blocked）マスクに登録。北側城壁と南側兵舎の間に「幅1ヘクスの狭路（チョークポイント）」を形成可能。

### [ADR-007] 射程到達判定付きA*経路探索と `/noctrl` 的接近挙動
- **決定**: ゴールを「ターゲット座標そのもの」ではなく、**「ターゲットからのヘクス距離 $\le \text{attack\_range}$ となる通行可能ヘクス」**とするA*アルゴリズム (`find_path_to_range`) を実装。
- **挙動**: ターゲットが射程外であればA*で1ヘクスずつ最短ルートで接近（障害物や他ユニットを自動迂回）。射程内に入った瞬間から移動を停止し、ASPDに基づく攻撃・スキル実行へシームレスに移行。

### [ADR-008] 空間タクティクス（AoE・ノックバック・陣形ロール）とガンビット拡張
- **決定**:
  - **範囲攻撃（AoE）**: 着弾点ヘクスおよび半径 $R$ ヘクス内の全敵ユニットへ同時ダメージ（例：【ファイアーボール】）。
  - **ノックバック**: 対象を攻撃者と逆方向のベクトルへ $D$ ヘクス弾き飛ばす。壁や他ユニットに衝突した場合は停止（例：【アローレペル】、【マグナムブレイク】）。
  - **陣形（Formation）**: 各キャラクターに `FormationRole`（`Frontline`, `Midline`, `Backline`）を付与し、前衛が狭路の栓となり後衛を守る初期配置を自動構成。
  - **空間ガンビット条件**:
    - `TargetDistanceAtLeast(u32)` / `TargetDistanceAtMost(u32)`
    - `EnemiesInRadius { radius: u32, min_count: usize }` （周囲に敵が密集したら範囲攻撃を発動）

これにより、将来的な2Dクォータービュー（アイソメトリック）GUI開発への道筋が完全に整いました。
