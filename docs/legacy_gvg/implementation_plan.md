# Implementation Plan: フェーズ3 - レガシー転生・パワーレベリング・ライバルギルド結成

## 1. 概要
フェーズ2で完成した「過剰精錬武器を持った先輩キャラたち」を活用した「セルフ養殖（パワーレベリング）」、世代交代で押し出された古参キャラがシナジー引力によってライバルギルドを形成する「サクセス×ペナント型ループ」、および新旧世代の模擬GvG（3対3パーティー対抗戦）を実装・検証します。

## 2. アーキテクチャと詳細設計

### A. 経験値・レベルアップとビルド育成方針 (`src/progression.rs`)
- **経験値計算**:
  - モンスター討伐時、生存しているパーティーメンバーで `base_exp` を等分（または育成枠へ均等配分）。
  - レベルごとの必要EXPテーブル（Lv1: 100, Lv2: 250, ... 指数増加）。
- **成長方針 (`GrowthPlan`)**:
  - `AgiCritPlan`: AGI 40%, STR 30%, LUK 20%, DEX 10%
  - `VitTankPlan`: VIT 50%, STR 25%, DEX 15%, AGI 10%
  - `DexLukCrafterPlan`: DEX 45%, LUK 45%, VIT 10%
  - `IntDexSupportPlan`: INT 50%, DEX 30%, VIT 20%
  - レベルアップごとにステータスポイント（Lv×3）を配分方針に従って自動割り振り。
- **レガシー転生 (`generation: u8`)**:
  - 世代が進むごとに、Lv1作成時の初期ボーナスステータスポイント（`(gen - 1) * 8`）が付与される。

### B. ギルド名簿とFA移籍システム (`src/guild.rs`)
- **ギルド名簿 (`Roster`)**:
  - 保有可能人数（例: 最大6名）。
  - 街のNPC化したメンバー一覧、移籍したメンバー一覧、ギルド資金プール。
- **ビルド特性タグ (`BuildTag`)**:
  - `PhysicalCarry`: STR・AGI・DEXが高く、攻撃に特化。
  - `WeaponSupport`: `PartyWeaponResearch` スキルを所持、またはDEX/LUKが高い。
  - `Tank`: VITが高く、`iron_defense` などの防御スキルを所持。
  - `MagicSupport`: INTが高く、オートスペルや魔法スキルを所持。
- **稼働スコア (`activity_score`) とFA退団**:
  - 出撃回数に応じてスコアが上昇、非出撃で減少。
  - 名簿上限超過時や低稼働時にFA宣言。
  - プレイヤーの選択:
    1. `Retain`（引き留め）
    2. `RetireAsTownNpc`（街のNPC化: 全員に常時武器ATK+3%などのパッシブ恩恵）
    3. `ApproveTransfer`（ライバルギルドへの移籍承認: レベルと装備に応じた移籍金Zeny獲得）
- **シナジー引力によるライバルギルドの自動編成**:
  - ライバルギルド: 『黒曜の旅団』（バランス・シナジー重視）
  - 移籍キャラの `BuildTag` を組み合わせ（例: `WeaponSupport` + `PhysicalCarry` + `Tank`）、自動的に最凶の3人パーティーを形成。

### C. 模擬GvG（3vs3パーティー対抗戦）エンジン (`src/engine.rs`)
- プレイヤー現主力パーティー（3名） vs ライバルギルド（かつての古参3名）のPvP戦闘。
- Tickベースで相互に攻撃、ヘイト（壁役優先）、必中バッシュ、オートスペル、武器研究オーラが激突。
- どちらかのパーティーが全滅するまで戦い、激闘ログと勝敗サマリーを出力。

## 3. 検証ステップ
1. **Step 1: パワーレベリング実証**
   - 新規第2世代Lv1キャラを、ソロ低レベル狩り vs 先輩（+10短剣シーフ＋ナイト）引率ハイオーク連戦で比較。
2. **Step 2: 世代交代とFA移籍**
   - 第5世代まで育成を進め、ギルド名簿を飽和。
   - 古参キャラを街のNPC化＆ライバルギルド『黒曜の旅団』へ移籍。
3. **Step 3: 模擬GvG対抗戦**
   - プレイヤー現主力（第5世代） vs 元弟子たちの黒曜の旅団（第1〜第3世代精鋭）の3vs3激闘。
4. **サマリー出力**
   - 養殖速度比較、ギルド変遷、GvG結果の包括的テーブル出力。
