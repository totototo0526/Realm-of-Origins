# Walkthrough: フェーズ3 - レガシー転生・パワーレベリング・ライバルギルド結成の実装

## 1. 実装概要
フェーズ3では、先輩キャラによる次世代の高速育成「**セルフ養殖（パワーレベリング）**」と、世代交代で押し出された古参キャラがシナジー引力によってライバルギルドを自動結成する「**サクセス×ペナント型ループ**」、および新旧世代の激突「**模擬GvG（3vs3パーティー対抗戦）**」を実装・検証しました。

## 2. 成果物と実装モジュール
- [src/models.rs](file:///media/ksp-zorin-001/WORK_DISK/プライベート/自作ゲーム/Realm%20of%20Origins/src/models.rs):
  - `Character`: `generation`（世代数）、`exp`（累積経験値）、`activity_score`（稼働スコア）
- [src/progression.rs](file:///media/ksp-zorin-001/WORK_DISK/プライベート/自作ゲーム/Realm%20of%20Origins/src/progression.rs):
  - レベルごとの累計必要経験値テーブル（`required_exp_for_level`）
  - ビルド育成方針（`GrowthPlan`: `AgiCrit`, `VitTank`, `DexLukCrafter`, `IntDexSupport`）によるステータス自動配分
  - レガシー転生ボーナス（世代 `generation` が進むごとに初期ステータスポイント加算）
- [src/guild.rs](file:///media/ksp-zorin-001/WORK_DISK/プライベート/自作ゲーム/Realm%20of%20Origins/src/guild.rs):
  - ギルド名簿管理（`GuildRoster`: 定員6名、街のNPC化、FA移籍承認、移籍金管理）
  - ビルド特性タグ（`BuildTag`: `PhysicalCarry`, `WeaponSupport`, `Tank`, `MagicSupport`, `HighFlee`）の自動判定
  - 稼働スコア低下による世代交代シフト処理（`process_generation_shift`）
  - シナジー引力（`calculate_synergy_score`）によるライバルギルド（『黒曜の旅団』）への自動入団と再鍛錬
- [src/engine.rs](file:///media/ksp-zorin-001/WORK_DISK/プライベート/自作ゲーム/Realm%20of%20Origins/src/engine.rs):
  - モンスター討伐時の経験値獲得（個体差ボーナス反映）
  - 模擬GvG（3vs3 オートチェス形式パーティー対抗戦 `simulate_gvg_battle`）
- [src/main.rs](file:///media/ksp-zorin-001/WORK_DISK/プライベート/自作ゲーム/Realm%20of%20Origins/src/main.rs):
  - Step 1: パワーレベリング実証（ソロ vs 先輩引率ハイオーク10連戦）
  - Step 2: 世代交代とFA移籍（街NPC化＆ライバルギルド自動結成）
  - Step 3: 現主力（第5世代）vs かつての愛弟子（黒曜の旅団）の模擬GvG対抗戦
  - 包括的検証サマリー出力

## 4. 総括と分析
1. **セルフ養殖の圧倒的加速**:
   フェーズ2で過剰精錬ダマスカスを完成させた先輩シーフ＆ナイトが格上ハイオークを瞬殺することで、Lv.1新キャラがわずか **815 Tick で Lv.27 (+26 レベル)** まで爆上がりしました。
2. **シナジー引力によるライバル結成**:
   出番の減った古参キャラたちが、互いの特性タグ（`WeaponSupport` と `PhysicalCarry`、`Tank`）に引き寄せられ、ライバルギルド『黒曜の旅団』で理想的な三位一体シナジー編成を自動形成しました。移籍金として **214,200 Zeny** の資金もギルドに還元されました。
3. **育てたキャラが立ちはだかるGvGドラマ**:
   かつて自分が育てて放出した古参タンク（重騎士バルガス）が第5世代エースの攻撃を耐え抜き、古参シーフ（クロード）が必中バッシュを連打して現主力を打ち破る劇的な展開が実現しました。「自分が手塩にかけて育てたビルドが、敵となっても強い」というサクセス×ペナント型ループの奥深さが実証されました。
