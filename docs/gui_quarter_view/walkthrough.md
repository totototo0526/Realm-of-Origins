# フェーズ7 ウォークスルー：Macroquad 2Dクォータービュー（2.5Dヘクス戦場＆ギルド司令部GUI）とステップ実行エンジンの実装

## 1. 概要とハイライト
フェーズ7では、これまでに構築されたデータ駆動型MMORPGシミュレーター（`WorldState`、BOM連動市場、自動派遣、過剰精錬、世代交代、A*ヘクス空間戦術エンジン）のヘッドレス互換性を100%維持しながら、**「リアルタイムで1 Tickずつ進行を観察・操作できるMacroquadベースの2DクォータービューGUI（1280x800）」**を完全実装しました。

### 主な実装成果
1. **戦闘エンジンのステップ実行化（ステートマシン化） (`src/engine.rs`)**:
   - `SpatialBattleSession` 構造体を新設し、1 Tick単位の進行メソッド `step_tick(&mut self, db: &ModDatabase) -> Vec<BattleVisualEvent>` を実装。
   - ユニットの移動、攻撃、ミス、クリティカル、AoE爆炎、ノックバック、討伐、ログを視覚イベント（`BattleVisualEvent`）としてGUI層へ通知。
   - 従来のループ処理を `create_chokepoint_session` と `create_gvg_session` のセッション生成ヘルパーへ集約し、約1,000行に及ぶ重複コードを削減。
2. **2.5Dクォータービュー・ヘクス戦場描画 (`src/gui.rs`)**:
   - `hex_to_pixel` / `pixel_to_hex` をベースに、縦比率0.58倍のアイソメトリック圧縮を施した六角形タイルを描画。
   - 建物フットプリント（障害物/壁）ヘクスには、前面3面の陰影ポリゴンと上面天板による**立体直方体ブロック（2.5D陰影）**を描画し、狭路（チョークポイント）が一目でわかる立体感を表現。
   - ユニットの扁平シャドウ、味方（青）、敵（赤/橙）、パワーレベリング養殖対象キャラ（金色＋★マーク）、頭上ネームプレート、HPゲージ、射程リングサークルを描画。
   - レーザー光線、斬撃クロス、AoE火炎サークルの爆発、頭上からのダメージ数値/`MISS`の浮遊フェードアウトエフェクトを実装。
3. **RO風チャット＆システムログウィンドウ (`src/gui.rs`)**:
   - 画面左下に半透明ブラック（Alpha 0.90）のログパネルを常設。
   - 戦闘進行Tick、レベルアップ通知、精錬の「クホホ…」ロスト、市場買い占めニュースがリアルタイムにスクロール。
4. **ギルド司令部ダッシュボード (`src/gui.rs`)**:
   - 画面右側に司令部パネルを配置。
   - **速度コントロール**: `一時停止` / `通常1x` / `高速3x` / `最大速`。
   - **作戦開始**: 『監視塔の隘路防衛 ＆ 養殖バトル』、『空間GvG模擬戦（宿敵：黒曜の旅団）』。
   - **ギルド運営**: 『クホホ精錬オーダー』、『市場ハック＆自動派遣』、『レガシー世代交代』、『セーブ＆ロード』。
   - **ユニット詳細ビュー**: クリックまたはホバーされたユニットのLv、HP、ATK、MATK、DEF、MDEF、HIT、FLEE、CRIT、ASPD、主武器（精錬値）、陣形ロール、ガンビットルールを一覧表示。
5. **日本語フォントの自動探索ローダー**:
   - Linux (Zorin OS/Ubuntu/Debian) の `/usr/share/fonts/opentype/ipafont-gothic/ipag.ttf` や `/usr/share/fonts/truetype/fonts-japanese-gothic.ttf`、Windowsのフォントパス等を自動探索して安全にロード。見つからない場合もクラッシュせず英語フォールバック。

## 3. アーキテクチャ設計 (ADR 要約)

### ADR-009: 戦闘エンジンのセッション化とステップ実行（ステートマシン）
- **決定**: 単発の一括ループ処理に加え、`SpatialBattleSession` を新設。
- **理由**: Macroquadのフレームループ（60FPS）から毎フレーム一定Tick（または速度に応じたTick数）を消化しながら描画層へイベントを送り、リアルタイム観戦・一時停止・早送りを実現するため。
- **利点**: `simulate_spatial_battle` や `simulate_spatial_gvg` はセッションを `while !session.is_finished` で回すだけの薄いラッパーとなり、コードの二重管理が解消された。

### ADR-010: 論理層と描画層の完全分離（ヘッドレス互換性の厳守）
- **決定**: `macroquad` のインポートおよび描画コードはすべて `src/gui.rs` と `main.rs` のエントリポイントに限定し、`engine.rs`, `world.rs`, `hex_grid.rs`, `models.rs` 等のコアロジックにはGUIクレートを一切持ち込まない。
- **理由**: CI環境やサーバー上での高速自動テスト（`cargo test`）、ヘッドレス回帰デモ（`--headless-demo`）、CUI対話モード（`--cli`）がディスプレイ環境なしで瞬時に動くことを保証するため。

### ADR-011: 2.5Dクォータービュー（アイソメトリック圧縮 ＆ 立体ブロック陰影）
- **決定**: Axialヘクス座標 `(q, r)` からスクリーンピクセルへ変換する際、`y` 軸座標を `0.58` 倍に圧縮。障害物ヘクスには高さ（20px）を与え、前面3面の側面ポリゴン（暗い石壁）と上面天板（明るい石壁）を描画。
- **理由**: 2D平坦な六角形グリッドに立体感が生まれ、監視塔の防壁や隘路（チョークポイント）が視覚的に際立つため。

### ADR-012: 日本語フォント自動探索ローダー
- **決定**: OS内の標準的な日本語フォント（Linux: `ipag.ttf`, `fonts-japanese-gothic.ttf`、Windows: `msgothic.ttc` 等）を配列から順次探索し、`load_ttf_font_from_bytes` でロード。見つからない場合は標準フォントで英語表記にフォールバック。
- **理由**: 外部アセットファイルの手動配置をユーザーに要求せず、初回起動時から日本語の文字化けを防ぐため。

## 5. 操作方法

| コマンド | 動作 |
|---|---|
| `cargo run` (または `cargo run -- --gui`) | **2DクォータービューGUIを起動** (1280x800ウィンドウ) |
| `cargo run -- --headless-demo` | 高速ヘッドレス自動検証スクリプトを実行 (CUI) |
| `cargo run -- --cli` | 従来のCUI対話型ギルドマスター司令部を起動 |
| `cargo test` | 全12件の単体・結合自動テストを実行 |

### GUI画面上の主な操作
1. **マウスホバー**: 戦場上の六角形タイルにカーソルを合わせると、水色の枠線でハイライトされます。
2. **ユニット選択**: 戦場上の味方・敵ユニットをクリックすると、右下パネルに詳細ステータス（HP、ATK、MATK、防御力、回避率、クリティカル率、ASPD、主武器、陣形、ガンビット）が表示され、射程リングが展開されます。
3. **再生速度変更**: 右上の `[一時停止]`, `[通常1x]`, `[高速3x]`, `[最大速]` で戦闘進行のスピードを切り替え可能。
4. **隘路防衛＆養殖**: ボタンクリックで『監視塔の隘路』が展開され、前衛がチョークポイントを塞いで後衛が狩るパワーレベリングがリアルタイム再生されます。
5. **空間GvG**: ボタンクリックで『栄光の騎士団闘技場』が展開され、宿敵『黒曜の旅団』との3vs3陣形激突がリアルタイム再生されます。
6. **クホホ精錬**: ボタンクリックで主力の武器を鍛冶屋が叩き、成功エフェクトまたは「クホホ…」の破損メッセージがポップアップ表示されます。
7. **市場ハック＆自動派遣**: ボタンクリックで物資の買い占め（BOM価格波及）と控え部隊の派遣・素材回収がワンクリックで実行されます。
8. **世代交代＆セーブ/ロード**: 殿堂入り世代交代や、ゲーム状態の保存・復元が画面上から実行可能です。
