# 実装計画: フェーズ9 自由なビルド実験・Auto-Wave＆DPS計測・敵の生態系シフトの実装

## 1. 目的とスコープ
フェーズ8で完成した2.5DクォータービューGUIを土台として、プレイヤーが自由にステータスや装備・カード構成を組み替えてビルドを実験し、Auto-Waveによる自動連戦を通じてリアルタイムにDPSや時給（EXP/Tick効率）の変化を観察できる環境を構築する。
さらに、プレイヤーのビルド偏重に応じて敵のモンスター編成が変化する「生態系シフト」や、ライバルギルドのロスターを偵察して指名対決できる空間GvGを実装する。

---

## 2. アーキテクチャ設計とADR（Architecture Decision Records）

### ADR-017: Auto-WaveステートマシンとWorldStateターン同期
- **背景**:
  単発の戦闘終了ごとに手動で開始ボタンを押す手間をなくし、放置周回・ハクスラ感覚で継続的な戦闘・報酬獲得とワールド進行（派遣・市場・裏リーグ）を連動させたい。
- **決定**:
  `GuiApp` に `auto_wave_enabled: bool`, `current_wave: u32`, `wave_transition_timer: Option<f32>` を追加。
  `session.is_finished` かつ `session.is_victory` かつ `auto_wave_enabled` の場合、2.0秒のインターバル演出後に次Waveのモンスター群を生成してセッションを再初期化。
  その際、`world.advance_turn(&db)` を呼び出し、裏の派遣・市場・ライバル成長を1ターン同期進行させる。
- **利点**:
  戦闘と経済・世代交代がリアルタイムに循環し、プレイヤーは何Waveも連続で戦いながらギルド資産とキャラの成長を体験できる。

### ADR-018: リアルタイムDPS・時給・命中/クリティカル率メトリクス集計
- **背景**:
  プレイヤーがステータスやカード、武器を変更した際に、「実際にどれくらい強くなったか」「攻撃速度やクリティカルの恩恵が出ているか」を客観的に評価する仕組みが必要。
- **決定**:
  `SpatialBattleSession` または `GuiApp` で以下のメトリクスを追跡：
  - `metrics_damage: u64` (セッション内の総与ダメージ)
  - `metrics_ticks: u32` (経過Ticks)
  - `metrics_hits: u32`, `metrics_attacks: u32` (命中率 = hits / attacks)
  - `metrics_crits: u32` (クリティカル率 = crits / hits)
  - `metrics_exp: u64` (獲得EXP)
  DPS = `metrics_damage as f32 / metrics_ticks.max(1) as f32`
  EXP効率 = `(metrics_exp as f64 / metrics_ticks.max(1) as f64) * 100.0`
- **利点**:
  ビルド変更直後にDPSの変化がリアルタイムに画面上部メトリクスバーで可視化される。

### ADR-019: 手動ステータス割り振りとリアルタイム戦闘反映
- **背景**:
  現在はレベルアップ時にGrowthPlanに従って自動割り振りされるが、プレイヤーが自発的に「STR極」「LUK/INT極（AS型）」「VIT/DEX壁型」などの特化ビルドを試せるようにしたい。
- **決定**:
  各キャラクターの `base_stats` に対して `[+1]`, `[+10]` ボタンおよび未割り振りステータスポイント（またはビルド実験用の全振りリセットボタン）をUIに提供。
  ステータス変更時に、`db.recalculate_character_stats` または `engine.calculate_combat_stats` を通じて、進行中の `SpatialBattleSession.team_a` の該当ユニットの戦闘ステータス（ATK, MATK, ASPD, DEF, HP, HIT, FLEE, CRIT, move_ticks）を即座に再計算して上書き。
- **利点**:
  戦闘中にステ振りを変更すると、即座に攻撃力や攻撃速度、クリティカル率が変化することを視覚的に実感できる。

### ADR-020: 敵の生態系シフト（軽量メタ適応Solver）
- **背景**:
  単一のビルド（物理近接のみ、長弓連射のみ等）で放置周回し続けると単調になるため、直近の攻撃傾向を学習して敵が対策構成（メタ編成）にシフトする仕組みを導入。
- **決定**:
  直近の与ダメージのうち「近接物理」「遠距離射撃」「魔法スキル」の比率を記録。
  - 近接物理が70%以上: 次のWaveは `Heavy`（重装高VIT・高DEF）比率が増加。
  - 遠距離・魔法が70%以上: 次のWaveは `Swift`（高FLEE・高ASPD・急速接近）比率が増加。
  - さらにWave 5以降は「物理反射オーラ」または「高耐久エリート個体」が出現。
  画面上部およびログに `[!] 生態系シフト: 敵が物理対策（重装型増加）を始めました！` と警告表示。
- **利点**:
  プレイヤーは敵の変異に合わせて、タブ1で「武器の持ち替え（短剣⇔弓⇔槍）」や「ガンビット（対Swift必中や対高VIT錐）」への切り替えを促される。

## 3. 実装ステップ
1. **`src/engine.rs` の拡張**:
   - `SpatialBattleSession` にメトリクス集計用フィールド（`total_hits`, `total_attacks`, `total_crits`）を追加。
   - `step_tick` 内で攻撃試行時、命中時、クリティカル発生時にカウントを更新。
2. **`src/gui.rs` の拡張**:
   - Auto-Waveトグルと次Wave自動遷移タイマーの実装。
   - 戦場上部メトリクスバー（Wave数、総DPS、EXP/100Tick効率、命中率、クリティカル率）の描画。
   - タブ1: 編集対象メンバー切り替え（主人公 / 同行者A / 同行者B）、各ステータスの `[+1]`, `[+10]`, `[Reset]` ボタンと戦闘ユニット即時同期。
   - タブ2: カード着脱・スロット合成UI、所持カード一覧（ヒドラ、炎眼、ソルスケ、ドレインリアー）と装着・全解除機能。
   - タブ4: 敵の生態系シフトSolver、ライバルギルド偵察と指名GvG開戦UI。
3. **総合検証**:
   - `cargo test`, `cargo run -- --headless-demo`, `cargo check`
