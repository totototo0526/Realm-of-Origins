# Walkthrough: フェーズ2 - 簡易ガンビットと過剰精錬（クホホ工場）の実装

## 1. 実装概要
フェーズ2では、敵の個体差に応じた戦術ルールを実行する「**簡易ガンビットシステム**」と、獲得したZenyと予備武器を投入して限界突破を目指す「**ワークオーダー式・過剰精錬（クホホ工場）**」を実装しました。
これにより、【戦闘 → 資金獲得（Overcharge） → 鍛冶屋による過剰精錬（ロストあり） → ガンビット最適化で再挑戦し討伐速度逆転】という古典MMORPGの理想的コアループを構築・実証しました。

## 2. 成果物と実装モジュール
- [src/models.rs](file:///media/ksp-zorin-001/WORK_DISK/プライベート/自作ゲーム/Realm%20of%20Origins/src/models.rs):
  - `Equipment`: `refine` (0〜15), `slots` (最大4), `is_locked` (希少品保護ロック)
  - `Skill`: `physical_multiplier`, `is_sure_hit` (必中フラグ)
  - ガンビットモデル: `Condition` (`TargetArchetypeIs`, `SelfHpBelow`, `Always`), `Action` (`UseActiveSkill`, `SwitchWeapon`, `NormalAttack`), `GambitRule`
  - `Character`: `gambit_rules: Vec<GambitRule>`
- [mods/core/skills.ron](file:///media/ksp-zorin-001/WORK_DISK/プライベート/自作ゲーム/Realm%20of%20Origins/mods/core/skills.ron):
  - 必中強撃スキル `bash` (倍率260%、必中判定) の追加
- [src/refinery.rs](file:///media/ksp-zorin-001/WORK_DISK/プライベート/自作ゲーム/Realm%20of%20Origins/src/refinery.rs):
  - 精錬成功率テーブル（+1〜+4は100%、+5以降段階低下）
  - 鍛冶屋職能シナジー（DEX/LUK極振りにより最大+15%の成功率底上げ）
  - 限界突破ボーナス（+7でASPD/クリティカル上昇、+10で防御無視固定ダメージ+120＆オートスペル率2倍）
  - 失敗時の「クホホ……」ロスト処理と、希少品ロック（`is_locked == true`）による安全装置
  - ワークオーダーバッチ精錬（`WorkOrder`: `BudgetBurn`, `SafeLimit`）
- [src/engine.rs](file:///media/ksp-zorin-001/WORK_DISK/プライベート/自作ゲーム/Realm%20of%20Origins/src/engine.rs):
  - ガンビット優先度評価と必中スキル判定
  - 過剰精錬の限界突破ボーナス（防御無視ダメージ、オートスペル率倍率）の戦闘反映
- [src/main.rs](file:///media/ksp-zorin-001/WORK_DISK/プライベート/自作ゲーム/Realm%20of%20Origins/src/main.rs):
  - Step 1: 初期狩り（資金・ベース武器準備）
  - Step 2: 全自動クホホ工場稼働（20本投入、+10目標バッチ精錬、完成品カード装着＆ロック）
  - Step 3: 過剰精錬武器 ＋ 対迅速型ガンビットによる下克上再挑戦
  - 3列比較サマリー（パーティーA vs パーティーB vs パーティーB改）の出力

## 4. 挙動の詳細分析
- **クホホ工場のドラマ**:
  未精錬ダマスカス20本を投入し、鍛冶屋の職能ボーナス（+14.6%）を受けながら過剰精錬を実行。途中で「クホホ……砕け散りました」のロストを経つつ、高精錬武器が生き残り、特化カード装着後に希少品ロックが適用されました。
- **迅速型ハイオークの討伐Tick差**:
  - 精錬前・ガンビットなし: 高FLEEにより攻撃ミス（MISS）が連発し、討伐に **532 Tick** を要していました。
  - 精錬後・対Swiftガンビット: 敵の迅速型を瞬時に検知し、必中スキル【バッシュ】で必中強撃（1発500〜700ダメージ）＋限界突破オートスペルを叩き込み、わずか **60 Tick**（約1/9の時間）で瞬殺しました。
