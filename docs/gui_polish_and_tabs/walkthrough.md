# フェーズ8: 2.5DクォータービューGUI視覚ポリッシュ ＆ マルチタブ・ギルド運営UI ウォークスルー

## 1. 概要と解決された課題
フェーズ7で構築したMacroquadベースの2.5Dヘクス戦場GUIにおいて判明した視覚的・操作的課題を全面的に解決しました。

1. **絵文字の「豆腐（`☒`）」化の完全排除**:
   - IPAゴシック等の日本語フォントに存在しないUnicode Emoji（`⚔️`, `🛡️`, `🧙`, `🗺️`, `🔨`, `📈`, `🏰`, `✨` 等）をすべて撤廃。
   - `[戦]`, `[防]`, `[魔]`, `[MAP]`, `[LOG]`, `◆`, `▶`, `★`, `■`, `▲`, `▼`, `[!]`, `[+]`, `[-]`, `[*]`, `[OK]`, `[NG]` などの確実に対応するJIS標準記号およびMacroquad図形描画へと置換。
   - 各種ボタンの高さに応じたフォントサイズ自動計算（11.0〜14.0px）とパディング適正化により、文字の枠外はみ出しを解消。

2. **戦場カメラ制御（パン・ズーム）とビューポート中心補正**:
   - 戦場領域（`x: 0 〜 830`, `y: 0 〜 535`）の中央にマップ重心が初期配置されるよう初期オフセット（`origin_x: 270, origin_y: 190`）を算出。
   - マウス右ボタンドラッグまたはWASD / 矢印キーによる無段階のスムーズなパン移動。
   - マウスホイール（およびQ/Eキー）による0.6倍〜1.8倍のズーム拡縮。
   - `[Reset]` ボタンおよびRキーによるワンタッチカメラ初期化。

3. **スマート・ネームプレート ＆ 攻撃射程・弾道エフェクト強化**:
   - **密集対策:** 通常時はユニット頭上に幅26pxのミニマムHPバーとロール記号のみを表示し、密集時の文字重なりを根本排除。
   - **詳細ポップアップ:** マウスホバーまたは選択中のユニットのみ、詳細情報（名前、職業、Lv、HP数値バー、射程）を最前面ポップアッププレートで描画。
   - **射程ハイライト:** 選択中ユニットの攻撃射程（`attack_range`）圏内の全歩行可能ヘクスを淡い緑色の六角形塗り＆枠線でハイライト。
   - **弾道パーティクル:** 弓攻撃の矢の飛翔線や、魔法スキルの火球・光球パーティクル（`TrajectoryParticle`）が発射元から着弾ヘクスへ飛び、着弾時に爆炎リングや斬撃エフェクトを展開。

4. **右側パネルの「マルチタブ・ギルド運営システム」進化**:
   - 4つの上部タブ（`[1:戦場/編成]`, `[2:工房/精錬]`, `[3:市場/派遣]`, `[4:名簿/転生]`）を実装。
   - 全ゲームサイクル（出撃・編成・過剰精錬・市場売買・自動遠征・レガシー転生・FA処遇・セーブ/ロード）がGUI上のクリック操作のみで完結。

## 2. 各タブの機能と操作仕様

### タブ1: `[1:戦場/編成]`
戦場の選択と進行速度、および出撃メンバーのリアルタイム戦術編成を担います。
- **作戦戦場展開:**
  - `[◆ 監視塔の隘路防衛 ＆ 養殖]`: 幅1ヘクスの隘路でモンスター群を迎撃し、後衛のLv1キャラを急速育成。
  - `[◆ 廃坑深層・坑道迎撃戦]`: 崩落した巨岩や支柱が入り組んだ狭い坑道でのタクティカル戦闘。
  - `[★ 空間GvG模擬戦]`: 宿敵『黒曜の旅団』との対称アリーナ決戦。
- **速度切替 ＆ カメラ:**
  - `[停止]`, `[1x]`, `[3x]`, `[MAX]`, `[Reset]` (カメラ初期化)。
- **ユニット編成カスタマイズ:**
  - **主武器の持ち替え:** `[短剣 (射程1)]`, `[長弓 (射程4)]`, `[槍 (射程2)]`, `[剣 (射程1)]` をワンクリックで即座に換装。セッション中の射程とステータスが即時反映。
  - **ガンビット作戦プリセット切替:** `[標準作戦]`, `[対Swift必中]`, `[対高VIT錐]`, `[密集AoE爆撃]`。
  - **陣形配置ロール:** `[前衛 (Frontline)]`, `[中衛 (Midline)]`, `[後衛 (Backline)]` を切替。

### タブ2: `[2:工房/精錬]` (クホホ工場)
所持武器や倉庫内の装備を選択し、段階的・自動的な過剰精錬とカスタマイズを行います。
- **装備選択リスト:** 装備中および倉庫内の武器一覧（精錬値、ATK、希少品ロック状態 `[L]`）を選択。
- **精錬アクション:**
  - `[+1 精錬する (300Z)]`: ドキドキの手動1回精錬。成功時は緑の画面フラッシュ、失敗（クホホロスト）時は赤の画面フラッシュと悲鳴ログを出力。
  - `[安全圏(+4)まで一括]`: 100%成功する+4まで一括精錬。
  - `[目標+7 限界突破]`: 限界突破（クリティカル率＆ASPDボーナス）を目指すバッチワークオーダー。
  - `[目標+10 神話突破]`: 神話限界突破（防御無視ダメージ＆オートスペル確率2倍）を目指す特注オーダー。
  - `[ロック切替 (誤破壊防止)]`: 希少品の誤精錬・誤ロストを防ぐセーフティロックのトグル。
  - `[空き枠へカード装着]`: 倉庫内のカード（スケルワーカーカード等）を空きスロットへ装着。

### タブ3: `[3:市場/派遣]` (BOM経済＆遠征)
材料市場のリアルタイム相場確認・売買と、控え部隊のオートチェス型自動派遣を管理します。
- **市場アイテムテーブル:**
  - 原木、鉄鉱石、鋼鉄、オリデオコン、白ポーションの現在価格、所持数、基準比の騰落率（`+X%` / `-X%`）を表示。
  - 各品目の `[買付x5]` および `[全売却]` ボタンで即座に売買し、BOM需要連動による価格連鎖をシミュレート。
- **自動派遣（遠征）:**
  - `[廃坑深層 (鉱石採掘)]` または `[薬草園 (ハーブ採集)]` を選択して遠征開始。
  - 画面上にリアルタイム進行度プログレスバー（0%〜100%）が表示され、完了時に素材・オリデオコン・Zenyを獲得してログへ報告。

### タブ4: `[4:名簿/転生]` (サクセス×ペナント管理)
世代交代（レガシー転生）とギルドメンバーのマネジメント、ライバルギルド情勢を管理します。
- **レガシー転生実行:**
  - 次世代の育成方針 `GrowthPlan`（`AgiCrit`, `VitTank`, `Crafter`, `Support`）を選択。
  - `[>> レガシー転生実行]` ボタンで先代英雄を控え名簿へ殿堂入り移籍し、次世代Lv.1ルーキーがギルドに加入。
- **ライバル3大ギルド戦力評価:**
  - 宿敵『黒曜の旅団』(Sランク)、『黄金の盾』(Aランク)、『蒼天の魔導会』(Aランク)の最新戦力状況を表示。
- **FA宣言キャラの処遇操作:**
  - `[引き留め]`: 5,000 Zenyの特別ボーナスを支給して残留。
  - `[街NPC化]`: 街の専属鍛冶屋に就任させ、精錬成功率を底上げ。
  - `[移籍承認]`: ライバルギルドへ移籍させ、次回GvGでの対戦相手として強化。
- **セーブ ＆ ロード:**
  - `[セーブ (save_data.ron)]`, `[ロード (save_data.ron)]` ボタンで即時永続化。

## 3. 検証結果
- **単体テスト**: `cargo test` 全12件 パス。

- **描画・操作**:
  - Unicode絵文字が一切含まれず、フォント文字化け（`☒`）が完全根絶。
  - 右ドラッグ・ホイールによるカメラ移動と、830pxビューポート中心補正が滑らかに機能。
  - 矢や魔法の弾道パーティクル、爆炎リング、スマートネームプレートが重なりなく美しく描画。
