# 実装計画：フェーズ8 2.5DクォータービューGUIの視覚ポリッシュとマルチタブ・ギルド運営UIの実装

## 1. 概要と目標
フェーズ7で立ち上がったMacroquad GUIの課題である「絵文字の豆腐（`☒`）文字化け」「カメラの戦場見切れ」「ユニットラベルの密集重複」「単発ボタンによる操作性不足」を解決し、**「GUIだけでゲームの全サイクル（ビルド構築・装備持ち替え・精錬・市場取引・自動派遣・世代交代・空間バトル）を滑らかにプレイできる本格的UI」**へ進化させます。

---

## 2. アーキテクチャと設計判断（ADR）

### [ADR-013] 豆腐文字（未定義グリフ）の完全排除と図形ベースUIアイコン
- **課題**: 通常の日本語TTFフォント（NotoSansCJKやIPAゴシック等）にはカラー絵文字（`🗺️`, `⚔️`, `🔨`, `📈` 等）が含まれず、画面上で四角いバツ印（`☒`）として描画されていた。
- **決定**:
  - `src/gui.rs` 内のすべての表示テキスト・ボタンラベル・ログメッセージからUnicode Emojiを全廃。
  - 代替として、JIS第1・第2水準に必ず含まれる記号（`◆`, `▶`, `★`, `■`, `[!]`, `[+]`, `[*]`, `(-)`) を採用。
  - 視覚的な強調にはMacroquadの図形描画（色付き丸バッジ、枠線、ハイライト色）を活用。

### [ADR-014] 仮想カメラモデル（パン・ズーム）とビューポート矩形
- **決定**:
  - 左側戦場エリア（`Rect::new(0.0, 0.0, 830.0, 545.0)`）を独立したビューポートとして扱う。
  - カメラ状態:
    ```rust
    pub struct CameraState {
        pub offset_x: f32,
        pub offset_y: f32,
        pub zoom: f32, // 0.6 〜 1.8 (デフォルト 1.0)
    }
    ```
  - マウス右ドラッグまたはWASDキーで `offset_x`, `offset_y` を更新。
  - マウスホイール（または `Q` / `E` キー、GUIボタン）で `zoom` を拡縮。
  - 座標変換:
    `screen_x = origin_x + offset_x + hex_pixel_x * zoom`
    `screen_y = origin_y + offset_y + hex_pixel_y * zoom`
  - 逆変換:
    `hex_pixel_x = (mouse_x - origin_x - offset_x) / zoom`
    `hex_pixel_y = (mouse_y - origin_y - offset_y) / zoom`
    により、ズーム・パン中も正確なマウスホバー・クリック選択を保証。

### [ADR-015] スマート・ネームプレートと弾道飛翔体パーティクル
- **決定**:
  - **通常時の描画**: 密集時の重なりを防ぐため、各ユニット頭上には幅28pxのミニマムHPバーと「Lv.X [ロール記号]」のみを描画。
  - **ホバー/選択時の描画**: カーソルが乗っている、またはクリック選択されたユニットのみ、頭上にフルネーム、現在HP/最大HP、陣形ロール、主武器タグを拡大ツールチップとして最前面にポップアップ。
  - **射程ハイライト**: 選択ユニットの `attack_range` 圏内の全ヘクスを薄いシアン/グリーンのヘクス枠で描画。
  - **飛翔体パーティクル (`TrajectoryParticle`)**:
    遠距離攻撃（弓、魔法）発生時に、発射元から着弾ヘクスへ向けて光弾や矢が移動するアニメーション（0.2秒程度）を描画し、着弾した瞬間にダメージ数値と爆炎リングを発生させる。

### [ADR-016] マルチタブ・ギルド運営UIステートマシン
- **決定**:
  - 右側パネル（幅420px）の最上部にタブバーを設置:
    `enum DashboardTab { Battlefield, Workshop, MarketDispatch, RosterLegacy }`
  - **タブ1 `[戦場/編成]`**:
    - マップ選択（隘路防衛、闘技場GvG、廃坑深層）、戦闘開始、速度制御。
    - 選択キャラクターの主武器持ち替え（短剣 ⇔ 弓 ⇔ 槍）、ガンビットプリセット切替（標準 / 対Swift必中 / 対高VIT錐 / 密集AoE）、陣形ロール切替（前衛 / 中衛 / 後衛）。
  - **タブ2 `[工房/精錬]`**:
    - 倉庫内の装備一覧リスト表示。
    - 選択装備に対する `[+1 精錬]`, `[安全圏+4まで]`, `[目標+7/+10 ワークオーダー]`, `[ロック切替]`, `[カード装着]`。
    - 成功時の緑色フラッシュ演出、クホホ失敗時の画面赤フラッシュ・ロスト表示。
  - **タブ3 `[市場/派遣]`**:
    - 市場アイテムのテーブル表示（品名、現在価格、在庫プログレスバー、基準価格比騰落率％）。
    - 各品目ごとの `[買付 x5]`, `[全売却]` ボタン。
    - 控え部隊の自動派遣（エリア選択、派遣実行、遠征進行度バー表示）。
  - **タブ4 `[名簿/転生]`**:
    - ギルド控えメンバー一覧（レベル、職業、稼働スコア）。
    - ライバル3大ギルドの戦力概要。
    - レガシー転生（世代交代・育成方針 `GrowthPlan` 選択）。
    - FA宣言中メンバーの処遇決定（残留 / 街NPC化 / FA移籍承認）。

## 3. 実装手順
1. `src/gui.rs` の絵文字を完全除去し、日本語フォント標準記号（`◆`, `▶`, `★`, `■`, `[!]`, `[+]` 等）と図形描画に置換。
2. カメラモデル（パン・ズーム・リセット）を実装し、戦場中央に初期オフセットを調整。
3. 弾道パーティクル構造体と射程ハイライト、スマートネームプレートを実装。
4. `DashboardTab` を追加し、4つのタブUIを実装。
5. `cargo test`, `cargo run -- --headless-demo`, `cargo check` で完全な動作を確認。
6. ドキュメント更新とコミット。
