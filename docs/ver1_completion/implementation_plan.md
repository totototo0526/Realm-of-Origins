# フェーズ10：Ver 1.0 完成マイルストーン 実装計画

## 概要
フェーズ9で実現した「自由なビルド実験・Auto-Wave・生態系シフト・ライバルGvG」を基盤とし、プレイヤーからのフィードバックである「左上HUDの重なりバグ」を根本解決します。また、正規育成としてのステータスポイント制と自由実験（Sandbox）の両立、およびハクスラRPGの華である「カード・多スロ装備の現物レアドロップ演出」を実装し、ギルド運営＆ハクスラRPG『Realm of Origins』の完成版（Ver 1.0）へ昇華させます。

---

## 変更設計

### 1. 画面左上HUDの2段レイアウト化 (`src/gui.rs`)
- **現状の課題**: `draw_battlefield` のマップタイトル（`y: 30.0`）と `draw_battlefield_metrics_bar` の背景（`y: 10.0..40.0`）が同位置で被り、文字が重複して判読不能になっている。
- **改修方針**:
  - `draw_battlefield` 冒頭での `[MAP] 戦場: 『...』` の直書き描画を撤廃。
  - `draw_battlefield_metrics_bar` を刷新し、上部HUDとして統括：
    - **1段目 (`y: 8.0, h: 24.0, x: 12.0, w: 806.0`)**: 背景ダークバー。`[MAP] 戦場: 『{name}』 | Tick: {tick} | ズーム: {zoom:.1}x` を表示。右端に `[Auto-Wave: ON/OFF]` ボタン（`w: 130.0`）を美しく整列。
    - **2段目 (`y: 36.0, h: 26.0, x: 12.0, w: 806.0`)**: メトリクスバー背景。`[Wave {wave}] | DPS: {:.1} | EXP: {:.0}/100T | 命中: {:.1}% | 会心: {:.1}%`、および `(次群まで {:.1}s)` を横並びに整列。
    - **警告バナー (`y: 66.0, h: 22.0`)**: 生態系シフト警告メッセージがある時のみ、その直下に警告バナーとして表示。
- **効果**: どの解像度・倍率でもHUDテキストが一切重ならず、情報が整然と視認できる。

### 2. ステータスポイント制と自由実験モードの両立 (`src/models.rs`, `src/progression.rs`, `src/gui.rs`)
- **データモデル**:
  - `Character` に `#[serde(default)] pub unallocated_pts: u32` を追加。
- **ポイント付与＆計算**:
  - `Progression::calculate_total_earned_stat_points(level: u32, generation: u8) -> u32`:
    - `(level.saturating_sub(1) as u32) * 6 + (generation as u32) * 10`
  - `Progression::grant_exp`: レベルアップごとに `character.unallocated_pts += 6;` を付与。
- **UI操作モード**:
  - `GuiApp` に `pub is_sandbox_mode: bool` を持たせる（初期値: `false` = 育成モード）。
  - 右上またはステ振り欄上部に `[モード: 育成(Pt消費)]` ⇔ `[モード: 自由実験(無制限)]` トグルボタンを配置。
  - **育成モード時**:
    - `残りステータスP: {unallocated_pts} Pt` を大きく表示。
    - `[+1]`, `[+10]` は残りポイントの範囲内でのみ割り振れる。
    - 極振りボタン（`STR極` 等）は「残りポイント全額」をそのステータスにすべて割り振る。
  - **自由実験モード時**:
    - ポイントに関係なく、自由に `+1`, `+10`, 極振り（+50）が可能。
  - **`[再振り]` ボタン**:
    - 全ステータスを10にリセットし、`calculate_total_earned_stat_points` で計算した総ポイントを `unallocated_pts` に全額プール。

### 3. モンスター討伐時の「カード ＆ 多スロ装備・現物レアドロップ」と視覚演出 (`src/gui.rs`)
- **ドロップ判定**:
  - 敵撃破時またはWaveクリア時にレアドロップ抽選を実行：
    - **カードドロップ (確率25〜35%)**: `hydra_card`, `flame_eye_card`, `soldier_skel_card`, `drainliar_card`, `andre_card` からランダム。
    - **ベース武器ドロップ (確率30〜40%)**:
      - `dagger` (ダマスカス), `bow` (ハンターボウ), `spear` (ランス), `sword` (グラディウス)
      - スロット数: 1〜4（ランダム抽選。4スロはレア！）
- **インベントリ即時連携**:
  - ドロップしたカードは `self.available_cards` および `self.world.storage_items` に格納。
  - ドロップした武器は `self.world.storage_equipments` に格納。
  - タブ2 `[工房/精錬]` のリストに即座に表示され、精錬やカード装着にそのまま使える。
- **レアドロップ視覚演出**:
  - 金色の特大フローティングテキスト `★ RARE DROP! [アイテム名] ★` をポップアップ表示（`lifetime: 2.5`、`color: Color::new(1.0, 0.85, 0.1, 1.0)`、`is_big: true`）。
  - チャットログにも目立つ金色メッセージを記録。

### 4. 右パネルのレイアウト調整（はみ出し防止）
- 各セクションの見出し・行間・パディングを最適化し、下端（`y: 780` 付近）を絶対にオーバーフローしないよう調整。
